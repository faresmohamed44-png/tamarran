# تمرّن: منصة نماذج الامتحانات (فرونت وباك في رابط واحد)

السيرفر (Node.js + Express) بيقدّم صفحات الموقع وواجهة الـ API من نفس الرابط، وقاعدة البيانات PostgreSQL.

## الشغال فيها
- تسجيل طلاب بحساب (إيميل وكلمة مرور) وتسجيل دخول.
- وحدات ← نماذج ← امتحان بتايمر وتصحيح على السيرفر وشرح لكل إجابة.
- حفظ كل المحاولات وأفضل نتيجة لكل نموذج.
- لوحة مدرس: إحصائيات، أصعب الأسئلة، آخر المحاولات، وإضافة/تعديل/حذف الوحدات والنماذج والأسئلة.
- الإجابات الصحيحة بتفضل على السيرفر ومبتتبعتش للطالب إلا بعد التسليم.

## المتغيرات المطلوبة (Environment Variables)
| الاسم | المعنى |
|---|---|
| DATABASE_URL | رابط اتصال PostgreSQL |
| JWT_SECRET | نص طويل عشوائي لتأمين الجلسات |
| ADMIN_EMAIL | إيميل حساب المدرس (بيتعمل تلقائيًا) |
| ADMIN_PASSWORD | كلمة مرور المدرس |
| NODE_ENV | اكتب production على الاستضافة |

## الرفع على الإنترنت (رابط واحد)
1. **قاعدة البيانات:** اعمل قاعدة PostgreSQL مجانية على Neon (neon.tech) أو Supabase، وانسخ رابط الاتصال (Connection string).
2. **GitHub:** ارفع محتوى الفولدر ده في repository جديد.
3. **Render:** من render.com اختار New ← Web Service، واربطه بالـ repository.
   - Build Command: `npm install`
   - Start Command: `npm start`
   - من Environment ضيف المتغيرات اللي فوق.
4. دوس Deploy. لما يخلص هيديك رابط واحد، افتحه وسجّل دخول بحساب المدرس وادخل "لوحة المدرس".

ملاحظة: الخطة المجانية في Render بتنام بعد فترة من عدم الاستخدام، فأول فتح بيتأخر شوية.

## التشغيل على جهازك
```
npm install
cp .env.example .env     # وعدّل القيم
npm run dev              # محتاج Node 20.6 أو أحدث
```
وافتح http://localhost:3000

## تعديل المحتوى
- من لوحة المدرس مباشرة (الأسهل).
- البيانات التجريبية في ملف `seed.js` بتتضاف أول مرة بس لو القاعدة فاضية.
- لكتابة معادلة أو أرقام بتظهر من الشمال لليمين، اكتبها بين `[[ ]]`.
